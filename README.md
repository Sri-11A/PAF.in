# 🧮 PAE-in: Financial Calculator  

A web-based tool for **loans, investments, and savings calculations** with precise results.

---

## ✨ Features  
- **Loan Calculator**: Estimate monthly payments and interest.  
- **Investment Growth**: Project future value with compound interest.  
- **Responsive Design**: Works on desktop and mobile devices.  

---

## 🚀 How to Use  
### Online (GitHub Pages)  
1. Visit the live demo:  
   `https://yourusername.github.io/PAE-in/` *(enable GitHub Pages first)*  

### Offline  
1. Download the repository.  
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge).
